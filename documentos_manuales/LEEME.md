# Documentos aportados a mano

Cuando un sitio bloquea la descarga o publica un documento en un visor embebido, guarde aquí el PDF con este nombre:

- `{codigo}_erd.pdf` para la Estrategia Regional de Desarrollo (por ejemplo, `AB080_erd.pdf`);
- `{codigo}_cuenta_publica.pdf` para la cuenta pública (por ejemplo, `AB085_cuenta_publica.pdf`).

`codigo/ods_documentos.py` los lee como si los hubiera descargado. Los PDF no se suben al repositorio; cada ronda registra su huella SHA-256. Ver el protocolo de revisión manual.
